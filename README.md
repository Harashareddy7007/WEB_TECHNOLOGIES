## 📖 About

This repository contains a set of mini-projects built as part of front-end framework coursework, each focused on practicing a specific web development concept — layout design, grid systems, form building, and UI interfaces.

---

## 📂 Mini-Projects

| # | Project | Description |
|---|---------|-------------|
| 01 | **Alliance Blackboard LMS** | UI design for a Learning Management System interface |
| 02 | **GitHub Login Page** | Recreated the GitHub login page layout using HTML & CSS |
| 03 | **Chess Board (CSS Grid)** | Built a chess board layout using CSS Grid |
| 04 | **ATM Interface Design** | Designed a front-end interface for an ATM system |

> 📄 Each project's documentation/report is available as a PDF in this repository.

---

## 🛠️ Tech Stack

- **HTML5** — structure & semantic markup
- **CSS3** — styling, layout, and CSS Grid
- **JavaScript** — interactivity (where applicable)

---

## 🎯 Purpose

These mini-projects were built to strengthen fundamentals in:
- Responsive layout design
- CSS Grid & Flexbox
- Recreating real-world UI (e.g. GitHub's login page)
- Building interactive interfaces from scratch
